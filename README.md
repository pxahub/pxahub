# ティリン

PXAHub と PXA Chain を開発しています。

> 海賊版サイトに流れる収益を減らす。

作品が正規の場所で見つかり、利用される選択肢を育てる。そのために PXAHub をつくっています。プラットフォームが成長することで、無断転載サイトへの流入と収益を減らすことを目指します。

同時に PXA Chain では、作品の権利情報をオンチェーンで記録・検証する仕組みに取り組んでいます。流通と権利の両面から進め、ひとつの対策だけに頼らない形を目指しています。

作品や知識を安心して共有できるコミュニティづくりも、この取り組みの一部です。

## 開発領域

- **PXAHub** — 正規の作品流通とコミュニティ体験
- **PXA Chain** — オンチェーンでの権利記録・検証に向けた基盤
- **技術** — Go、TypeScript / React、ブロックチェーン基盤

PXAHub は現在クローズドプレビュー中です。ソースコードは非公開で、公開情報はこのプロフィールでお知らせします。
