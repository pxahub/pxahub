## 取り組んでいること

- **PXAHub** — 共有から人とアイデアがつながるコミュニティを目指しています。
- **バックエンド** — Go を中心に、API と運用基盤を開発しています。
- **フロントエンド** — TypeScript と React で、使いやすい体験を形にしています。
- **Web3** — ブロックチェーンを使った仕組みや開発者向けツールに取り組んでいます。
